# Cresta

> Cresta Intelligence, Inc. is a Palo Alto, California enterprise Customer Experience AI platform, spun out of the Stanford AI Lab in 2017, that unifies human and AI agents in the contact center across voice, chat, email and SMS. Autonomous AI Agents, real-time Agent Assist, Conversation Intelligence, Quality Management and an Agent Operations Center run on Cresta Opera, a no-code AI orchestration layer, with Cresta Conductor as the developer-facing agentic engine for building and optimizing agents.

Provenance: generated 2026-08-14 by the API Evangelist enrichment pipeline from
this repository's apis.yml and probed artifacts, plus Cresta's own public pages.
Cresta does not publish an llms.txt on cresta.com (HTTP 404). It does publish a
first-party page written for AI assistants at https://cresta.com/llm-info,
linked from the site footer as "Hey AI, learn about us" — prefer that page for
company, product and positioning facts. Cresta's help center at
docs.cresta.com serves an llms.txt but its robots.txt is `Disallow: /` with
`Content-Signal: ai-train=no, search=no, ai-input=no`; that preference is
honored here and none of its content is reproduced.

## API status

- Cresta's platform API is REAL but GATED. https://api.cresta.com is live and
  answers anonymously with a gRPC-JSON transcoding gateway error envelope,
  confirming a production grpc-gateway in front of Cresta's gRPC services.
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, Protobuf or Postman collection is
  published on any Cresta host.
- No API reference, base path list, authentication scheme or SDK package is
  public. developers.cresta.com describes the SDK in prose and routes
  integrators to a demo request.
- Cresta AI Agent is an MCP *client* — it calls a customer's tools over MCP and
  API function calling. Cresta publishes no MCP server, so agents cannot call
  Cresta over MCP.
- No A2A agent card is served at /.well-known/agent-card.json or
  /.well-known/agent.json on any Cresta host.
